# BatchReptillian

This chess engine is an improvement on "BatchMammal". To be more specific, this project has 2 goals in mind:

1. Improve the handling of positions in the computer's memory, boosting the amount of calculations it can perform

2. Use the engine's match history to, under the auspices of some sort of statistical analysis,  
tweak a litany of numerical parameters utilized in the evaluation function

It's a prelude to the Esmare chess engine, which seeks to be a more fleshed out take on the machine learning aspect of chess programs.
Such a holistic stride primarily involves (at least in my mind) the use of neural networks to interconnect the aforementioned group of
"neurons". The resulting network (hopefully) implies a nuanced decision making process that depends on the different factors
present in the current position and how they all influence the present game state. Although, for the time being I'll concern myself with
my flawed, but easier to implement evaluations

This project is an amateur endeavour. I don't take issue with you using it for whatever pleases you :p
